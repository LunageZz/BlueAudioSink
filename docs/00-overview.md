# 项目总览

## 1. 目标

把手机音频低延迟、稳定地传到电脑。提供两种可选模式：

- **蓝牙模式**（已有）：无需手机安装 App，Windows 系统级 A2DP 接收。
- **Wi-Fi 模式**（新增）：手机端 App 采集 + UDP 传输，延迟更低、不受 2.4G 射频干扰。

两种模式互斥，用户在主界面切换。

## 2. 双端关系

\`\`\`
┌─────────────────────┐         UDP          ┌──────────────────────┐
│  Android 发送端      │  ────────────────>   │  PC 接收端            │
│  MediaProjection    │  PCM 48k/16bit/stereo │  UDP 抖动缓冲         │
│  AudioRecord        │  10 ms/包             │  WasapiOut 播放       │
│  前台服务           │  PING/PONG 测 RTT     │  延迟/丢包统计         │
└─────────────────────┘                      └──────────────────────┘
\`\`\`

- 手机端是**权威状态源**：开始/停止由用户在主界面手动触发。
- PC 端被动接收，自动调节抖动缓冲以保稳定。
- 发现机制：PC 每 2 秒 UDP 广播自身；手机可自动发现，也可手动输入 IP。

## 5. 开发流程（强制）

1. 先在本目录写清思路与规格；
2. 规格评审通过后再写代码；
3. 实现与文档不一致时，**先改文档再改代码**；
4. 每阶段回填实测数据（延迟、丢包、断点）；
5. 分阶段 git 提交，工作区保持干净。

## 6. 验收基线

| 指标 | 目标 |
| --- | --- |
| 端到端延迟 | 正常 ≤ 80 ms，抖动自适应 ≤ 150 ms |
| 丢包率 | < 0.5% |
| 30 分钟断点 | ≥100 ms 断点 0~1 次 |
| Android 内存 | ≤ 100 MB |
| 蓝牙模式 | 切换后功能不回归 |
