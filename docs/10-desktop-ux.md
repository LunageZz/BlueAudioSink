# 电脑端界面与交互优化（2026-10-30）

## 目标与边界

保留 Win32/GDI、蓝牙/Wi-Fi 互斥机制和现有音频协议。此次主要修改界面组织、状态呈现和设置入口，不调整传输/补偿算法。

## 实施规格（先于实现）

- 顶部固定导航：品牌、蓝牙、Wi-Fi、设置。设置在 Wi-Fi 右侧，两模式及设置页均可访问；返回设置前的模式，不停止音频。
- 将状态从导航行中独立成主卡片，使用大标题、简短说明和手机/接收/输出三个阶段。不能把收到静音 PCM 等同于正在播放有声内容。
- 对 Wi-Fi 增加只读观测：最近音频包年龄、最近非静音信号、输出播放器是否实际工作、排空/恢复阶段、当前输出设备名。它们不参与音频调度；UI 据此区分等待连接、待发送、准备播放、播放中、当前静音、暂时中断、恢复中、故障。
- Wi-Fi 页按状态、设备流向、三项核心指标（网络往返、缓冲、近 10 秒丢包）组织。端口、累计收包/缺包/恢复次数放入“连接详情”展开区。删除成串的互斥机制和缓冲解释。
- 共享设置按通用与连接偏好分组：播放设备、开机启动、蓝牙自动连接、Wi-Fi 预缓冲档位（80/120/160 ms）、日志入口。蓝牙专属选项明确标识；缓冲档位只改现有首次/恢复阈值，不改正在播放的 PCM。
- 在设置中主动更换播放设备时，蓝牙沿用既有路由设置，Wi-Fi 请求后台重建输出播放器；模式不变。页面显示实际输出名，不能用列表第一项冒充当前输出。
- 保留按需重绘与双缓冲。补齐键盘 Tab/Enter/Space/Escape、焦点描边、按钮按压/悬停反馈和无效控件的禁用态。
- 默认窗口约 700×680 DIP（最小外框 600×640 DIP），设置最小尺寸以避免裁切；宽屏内容居中并限制最大宽度，文字按 DPI 缩放，状态与导航不抢同一行。

## 验证

构建、原音频回归、状态映射回归；桌面实测 Wi-Fi/蓝牙切换、从两模式进入同一设置页、返回、详情展开/折叠、键盘操作、下拉、最小窗口和较大窗口。完成后同步本地 Release 并提交 Git。


## 完成与核验

- 全局设置入口位于 Wi-Fi 按钮右侧，蓝牙/Wi-Fi/设置页共用导航；进入/返回设置不切换模式。
- 首页按主状态、发送/输出设备、三项指标分层，默认收起端口与计数。撤下不够严谨的单程“估算延迟”，显示有明确测量语义的网络往返时间；静音根据收到的 PCM 判断，不受电脑其他应用出声影响。
- 修正电脑地址选择：有手机端点时按该端点的本机路由取地址；待连接时优先活动 Wi-Fi 地址，避免显示无关 VPN 地址。增加复制地址与故障重试。
- 设置按播放/启动和模式连接偏好组织，蓝牙专属选项明确标识。80/120/160 ms 使用已有预填/恢复阈值，测试选择 120 后已恢复原 80 ms；更换输出时只重建输出播放器，不改变传输协议。
- 增加原生最小尺寸、最大化、宽屏最大内容宽度 820 DIP、键盘焦点和禁用状态。修正返回后焦点框残留、下拉字体随 hover 改变、悬停边框传参无效的问题。
- 发布构建成功，C# 编译 0 错误；裁剪发布仅有既有 NAudio/COM 警告。原有 10 项音频回归和新增 5 项状态映射测试共 15 项通过。
- 桌面实测：两种模式进入同一设置页、返回保留当前模式、详情开关、输出就地下拉与 Escape、预缓冲选择与保存反馈、Tab/Enter 返回焦点、窄窗口及最大化/还原均完成。窄窗口宽度约为最小外框 600 DIP，核心卡片和设置未越界。
- 进入设置、操作显示层不主动停止发送/接收；本轮没有重新录制真机音质样本。音频算法沿用已修复版本，连接状态通过只读观测细化；不把 UI 单元测试写成真机传输验收。
- 当前保留 Win32/GDI 与原依赖，无新增 UI 框架或图片资源。自绘控件支持键盘操作，本轮未新增完整 UI Automation 节点。

本地 Release 同步到 `artifacts/BlueAudioSink-0.1.0.exe`、`artifacts/pc/BlueAudioSink.exe` 及默认 publish 目录；Android 产物本轮不变。
